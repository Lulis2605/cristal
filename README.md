# ONG Cristal

Sistema de gestão de doações para a ONG Cristal.
Projeto Integrador Extensionista II · ADS.

## Requisitos

- Git
- Vite+ (comando `vp`): https://viteplus.dev

## Como rodar

1. Clone o repositório e entre na pasta:
   ```bash
   git clone https://github.com
   cd cristal
   ```
2. Instale as dependências:
   ```bash
   vp install
   ```
3. Copie `.env.example` para `.env`
4. Terminal 1, inicie a API:
   ```bash
   vp run api
   ```
5. Terminal 2, inicie o frontend:
   ```bash
   vp dev
   ```
6. Abra `http://localhost:5173`
