# cristal

Sistema de gestao de doacoes para a ONG cristal. Projeto Integrador Extensionista ADS.

## Requisitos

- Git
- Vite+ (comando vp): https://viteplus.dev

## Como rodar

1. Clone o repositorio e entre na pasta:
   git clone https://github.com
   cd cristal
2. Instale as dependencias:
   vp install
3. Copie .env.example para .env
4. Terminal 1, inicie a API:
   vp run api
5. Terminal 2, inicie o frontend:
   vp dev
6. Abra http://localhost:5173
